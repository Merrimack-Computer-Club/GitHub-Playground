# Useful Resources

A shared list of websites, videos, tools, and guides that students have found helpful for learning Git and GitHub.

## How to Contribute

Adding a resource is one of the options in [Exercise 06](exercises/exercise-06-documentation-update.md). To add one:

1. Create a branch, like `yourname/add-resource`.
2. Add a row to the table below with the link, a short note on what it's good for, and your name or handle.
3. Commit, push, and open a Pull Request.
