# Student Profiles

A place to introduce yourself and see who else is practicing here. Adding a profile is one of the options in [Exercise 06](../exercises/exercise-06-documentation-update.md).

## How to Add Your Profile

1. Create a branch, like `yourname/add-student-profile`.
2. Create a new file in this folder named `yourname.md` (e.g. `peter.md`).
3. Fill it in using the template below.
4. Add a link to your file in the **Profiles** list at the bottom of this page.
5. Commit, push, and open a Pull Request.

## Template

Only your name or GitHub handle is needed. Everything else is optional, so share only what you're comfortable with. Feel free to add your own categories such as career aspirations, fun facts, or Discord username.

```markdown
# Your Name or Handle

- **Name**
- **Major:**
- **Class year:**
- **Interests:**
- **GitHub:** [@your-github-username](https://github.com/your-github-username)
```
