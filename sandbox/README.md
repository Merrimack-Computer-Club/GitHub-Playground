# Sandbox

This is a free-form practice area. You can add, edit, or delete anything in this folder without worrying about breaking anything important.

## Ideas for Practice

- Add a random line and then revert it with `git revert`
- Create a file, delete it, and restore it with `git checkout`
- Practice writing different styles of commit messages
- Experiment with `git log`, `git diff`, and `git blame`
